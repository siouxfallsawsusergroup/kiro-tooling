# kiro-tooling

Community-shared Kiro skills, steering files, and agents from the [Sioux Falls AWS User Group](https://www.siouxfallsawsuser.group/). Members can clone this repo and use whichever pieces they want.

## What belongs here

- **Skills** — Kiro skills the group wants to share
- **Steering** — steering files for shared conventions
- **Agents** — agent definitions members can reuse

Add files under those categories as they are ready to share.

## How to use

```bash
git clone https://github.com/siouxfallsawsusergroup/kiro-tooling.git
```

Point Kiro at this checkout, or copy the skills, steering files, and agents you want into your own project.

## Contributing

Pull requests are welcome. Open a PR with the skill, steering file, or agent you want to share. Keep changes small and easy to review.
